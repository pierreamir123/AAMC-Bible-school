## افتراضات المرحلة ١ وما بعدها
- الفريق **٥-٩ خدام بالغين**، كل حارة (Persona) فيها خادم أو اثنان.
- الأولاد: تالتة ابتدائي (نحو ٨-٩ سنين) وأولى إعدادي (نحو ١٢-١٣) في الـPilot؛ فالخادم يتعامل مع أطفال صغار ومراهقين صغار، فتلزم **حماية أطفال** (من الـprompt: إلزامية).
- لا ميزانية معروفة ولا حجم دفعة معروف؛ أي رقم تكلفة أو جهد **تقدير**.
