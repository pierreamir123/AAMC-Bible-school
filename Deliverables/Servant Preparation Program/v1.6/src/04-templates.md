## ٠٤-ج · تدفق التواصل (صفحة واحدة)

| القناة | الاستخدام | القاعدة |
|---|---|---|
| الاجتماع الأسبوعي | القرارات ومراجعة العمل | الموعد ثابت، والمحضر سطران |
| جروب الفريق | تنسيق سريع | لا قرارات هنا؛ القرار يُكتب في سجل القرارات |
| جروب الأهالي | معلومات الأسبوع فقط | رسالتان أسبوعياً كحد أقصى، يديره الأمين والمضيف |
| المكتبة والـ Backlog | مصدر الحقيقة للمنتجات | اسم وإصدار لكل ملف |
| التصعيد | مشكلة أو خلاف | قائد الحارة ← أمين الخدمة ← المسؤول الكنسي |

**في الأزمة** (غياب خادم قبل الفصل، مشكلة مع طفل أو ولي أمر): ١) أبلغ قائد الحارة فوراً ٢) إن تعلق بطفل أبلغ مسؤول الحماية ٣) لا تحل وحدك.

## ٠٤-د · قائمة حماية الأطفال (قبل كل لقاء)

**سياسة الكنيسة هي المرجع. هذه قائمة عامة مقترحة (يتأكد من الكنيسة).**
- [ ] بالغان على الأقل في القاعة طوال الوقت
- [ ] قائمة حضور الأولاد جاهزة
- [ ] لا يُسلَّم طفل إلا لولي أمره أو من يفوّضه
- [ ] لا صور أو تسجيل بلا إذن الأهل
- [ ] لا تواصل خاص مع الأطفال
- [ ] أبواب القاعة مفتوحة أو بها نافذة
- [ ] رقم المسؤول للطوارئ متاح
- [ ] أي ملاحظة غير عادية تُسجَّل وتُبلَّغ اليوم نفسه

**إقرار:** اطلعتُ على قواعد حماية الأطفال وأتعهد بتطبيقها. الاسم: …………… التوقيع: …………… التاريخ: ……………

## ٠٤-ز · نموذج prompt وقائمة التحقق

**قالب prompt لصنع منتج:**
```
الدور: أنت مصمم محتوى تعليمي لأولاد عمرهم [..].
السياق: مدرسة كتاب مقدس في كنيسة قبطية. الهدف: [..].
المهمة: اصنع [منتج] عن [موضوع].
القيود: لغة بسيطة، لا معلومات لاهوتية أو طقسية جديدة، وضّح أي افتراض.
الشكل: [جدول / نقاط / نص قصير].
```
**قائمة التحقق قبل الاستخدام:**
- [ ] هل كل المعلومات الكتابية صحيحة؟ (راجع الكتاب بنفسك)
- [ ] هل في ربط لاهوتي أو طقسي؟ ← للمراجعة الكنسية
- [ ] هل اللغة مناسبة للعمر؟
- [ ] هل اخترع الـ AI أرقاماً أو مصادر؟
- [ ] هل أدخلتُ أي بيانات عن الأولاد؟ (يجب ألا يحدث)

## ٠٤-ح · بطاقات الأسئلة الصعبة (للتمرين)

| # | السؤال |
|---|---|
| ١ | لماذا يسمح الله بالألم؟ |
| ٢ | هل يتعارض الإيمان مع العلم؟ |
| ٣ | كيف نعرف أن الكتاب لم يتغير؟ |
| ٤ | هل المعجزات ممكنة؟ |
| ٥ | لماذا لا يمنع الله الشر؟ |
| ٦ | لماذا يبدو في الكتاب أحياناً أن القصص تتعارض؟ |
| ٧ | هل الله موجود فعلاً؟ |
| ٨ | لماذا نصلي إن كان الله يعرف كل شيء؟ |
| ٩ | لماذا الكنيسة؟ ألا يكفي أن أصلي وحدي؟ |
| ١٠ | ماذا أقول لصديق يسخر من إيماني؟ |
**طريقة التمرين:** يسحب خادم بطاقة ويجيب في دقيقة بدليل وبهدوء؛ والمجموعة تقيّم: هل استند للكتاب؟ هل كان هادئاً؟ هل قال «لا أعرف» حين لزم؟ *(الإجابات اللاهوتية تُراجَع مع الكنيسة)*.
