كودان يحكمان العمل

الروح (Spirit)

Without system everything dies

لا خدمة تعيش بلا نظام يحميها: Code ومواعيد وهيكل ومسؤوليات واضحة.

الهيكل العظمي (Skeleton)

Walk the Talk

نُحضَّر بالطريقة نفسها التي سنقدّم بها، فالتحضير نموذج للتقديم.

الكود الأول للروح: Without system everything dies. الكود الثاني للهيكل العظمي: Walk the Talk. كلاهما قرار من صاحب الخدمة.
